# Beyond the Veil

**Revealing the Truth About Authority, Obedience, and the Heart**  
By Bradley Hobbs

## About the Project

*Beyond the Veil* is a Christian teaching book and companion website exploring biblical authority, obedience, spiritual leadership, accountability, discernment, correction, and the condition of the heart before Jesus Christ.

The project invites readers to examine their own lives with humility, pursue truth with integrity, and recognize that human authority is never beyond accountability to God. It also emphasizes that forgiveness does not erase the need for wisdom, healthy boundaries, or appropriate support when harm has occurred.

The website organizes the book into individual reading pages, a table of contents, supporting resources, and information about the book and author.

## Design and Accessibility

The website uses a burgundy, gold, and cream visual theme. Pages share consistent navigation and footer links and are built with responsive HTML and CSS for reading across desktop and mobile screens.

The content is arranged as individual pages to make the book easier to navigate, read, and discover. Scripture references are included for readers to study in context.

## Technology

- HTML5
- CSS
- GitHub repository for version control and source files
- GitHub Pages as the intended static website host

No build system is required for the basic static HTML and CSS pages.

## Local Preview

To preview the website locally, download or clone this repository and open `index.html` in a browser. For a local web server, run a static server from the repository root and visit the local address it provides.

## Publishing with GitHub Pages

The website is now published through GitHub Pages at:

https://brad-hobbswd.github.io/beyond-the-veil/

The source files are maintained in this repository. After any future updates, allow GitHub Pages time to deploy the changes, then test the published pages and navigation on desktop and mobile. If deployment settings need to be reviewed, open the repository settings and select **Pages** to confirm the `main` branch and repository root (`/(root)`) are selected.

## Search Engine Discovery

The repository includes `sitemap.xml` to help search engines discover the site's pages. Once the website is live:

1. Open the published website and test that its pages load correctly.
2. Confirm that the sitemap URL is accessible at `/sitemap.xml`.
3. Submit the sitemap through Google Search Console and Bing Webmaster Tools.
4. Check the homepage, book page, chapter pages, conclusion, and resources page for correct titles, descriptions, navigation, and mobile readability.

Search engines may take time to crawl and index new or updated pages. A sitemap supports discovery but does not guarantee indexing or ranking.
